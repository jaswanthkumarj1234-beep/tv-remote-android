# TV Remote for Samsung TVs

Control a Samsung smart TV from an Android phone. No laptop, no account, no internet needed: the phone talks straight to the TV over your home Wi-Fi.

## Download

**[Download TVRemote.apk](https://github.com/jaswanthkumarj1234-beep/tv-remote-android/releases/download/latest/TVRemote.apk)**

## Set up (2 minutes, once)

1. Open the downloaded file on the phone. If Android asks, allow "Install unknown apps" for your browser, then tap Install.
2. Connect the phone to the same Wi-Fi as the TV, switch the TV on, and open **TV Remote**.
3. The app finds the TV by itself. When the TV shows **Allow**, press it with the TV's own remote.
4. For **Power on** from the phone: on the TV open Settings > General > Network > Expert Settings and turn on **Power On with Mobile**. The app learns the TV's address by itself the first time it connects.

## What it does

- Arrow keys, OK, Back, Home, volume, channels, number pad, play/pause
- Swipe pad, app buttons (YouTube, Netflix, Prime Video, Hotstar)
- Type on the TV from the phone keyboard (including YouTube's letter grid)
- Power on / power off
- Finds the TV again by itself if its IP address changes
- Optional **Laptop** tab to control a Windows laptop running LaptopPad (not needed for TV use)

## Notes

- Phone and TV must be on the same Wi-Fi.
- Samsung does not allow a system-wide mouse pointer on the TV, so there is none.
- To update, download the new APK and install over the old one.
- The app is built automatically by GitHub Actions from this source code.
